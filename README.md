# 📚 คู่มือเรียนและสรุปเนื้อหาเตรียมสอบ
## วิชา โครงสร้างข้อมูลและอัลกอริทึม (Data Structure and Algorithm)
**สาขาวิชา**: ระบบสารสนเทศ คณะบริหารธุรกิจ มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน

---

### 📌 ยินดีต้อนรับสู่ GitBook สรุปวิชา Data Structure!
หนังสือออนไลน์เล่มนี้จัดทำขึ้นเพื่อรวบรวมเนื้อหาสำคัญจากเอกสารการเรียน บทที่ 1 ถึง บทที่ 5 สำหรับใช้อ่านทบทวนเตรียมตัวสอบกลางภาคและปลายภาค ประกอบด้วย:

1. **บทที่ 1**: ความรู้เบื้องต้น, ประเภทโครงสร้างข้อมูล, SDLC, Flowchart, Pseudocode และ Big-O Notation
2. **บทที่ 2**: อาร์เรย์ (Array) 1 มิติ, 2 มิติ, 3 มิติ และสูตรการคำนวณตำแหน่งในหน่วยความจำ
3. **บทที่ 3**: สแตก (Stack - LIFO), การแปลง Infix -> Postfix, การประมวลผล Postfix และ Recursion
4. **บทที่ 4**: คิว (Queue - FIFO), คิวเชิงเส้น, ปัญหา False Overflow และคิวแบบวงกลม (Circular Queue)
5. **บทที่ 5**: ลิงค์ลิสต์ (Linked List), Singly Linked List, Doubly Linked List และ Circular Linked List
6. **🎯 สรุปจุดเน้นการสอบ**: รวบรวมสูตรคำนวณและข้อระวังที่มักออกสอบประจำ
