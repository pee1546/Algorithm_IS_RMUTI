1. **บทที่ 1**: ความรู้เบื้องต้น, ประเภทโครงสร้างข้อมูล, SDLC, Flowchart, Pseudocode และ Big-O Notation[cite: 1]

5. **บทที่ 5**: ลิงค์ลิสต์ (Linked List), Singly Linked List, Doubly Linked List และ Circular Linked List[cite: 5]
